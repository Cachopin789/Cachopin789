## Proyecto destacado

### [FruitTales Video Pipeline](https://github.com/Cachopin789/fruittales-video-pipeline)

Pipeline de automatización para la post-producción de vídeo del canal de YouTube **FruitTales**.

- Mejora y normaliza el vídeo para distintos formatos, incluido 16:9.
- Automatiza borradores de títulos, descripciones, hashtags y prompts de miniatura.
- Centraliza tareas de edición para que el proceso sea reproducible y fácil de revisar.
- Incluye ajustes de audio orientados a reducir el riesgo de reclamaciones, siempre revisando los derechos de uso del material.

`Python` · `PowerShell` · `FFmpeg` · `Automatización`
